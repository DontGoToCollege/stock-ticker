# Stock Ticker

A small stock-price page that runs on your own computer. Type a company or ticker symbol to see its price, a chart (1 day to 5 years) and recent news, and read news articles in a clean built-in reader.

It gets its data from Yahoo Finance, so it needs an internet connection, but no account or API key.

## Use it

1. Install [Python 3](https://www.python.org/downloads/) if you don't have it.
2. Double-click `Start Stock Ticker.bat` (or run `python server.py`).
3. Your browser opens at http://127.0.0.1:8750. Close the black window to stop it.

The page is only reachable from your own computer.

## Download

Download the code from the [latest release](https://github.com/DontGoToCollege/stock-ticker/releases/latest) (`Source code (zip)`) and unzip it.
